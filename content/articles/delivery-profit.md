## 一个真实的经营问题

「外卖一天 80 单，怎么月底比只做堂食时还紧张？」

因为外卖订单的收入要分给的人特别多：平台要佣金、骑手要配送、餐盒要钱、满减要商家承担一部分、推广点击也要钱。剩下的才是这一单对房租和人工的贡献。营业额是加法，这些费用是一串减法。

## 为什么会出现这个问题

外卖后台通常把「营业额」「订单量」放在最显眼的位置，而费用分散在佣金、活动、配送、推广等多个报表里。老板每天看到的是加法的那一栏，月底才把减法加总，认知自然错位。

第二个原因是口径：佣金按标价还是实付、配送费谁承担、满减里平台补多少，各家平台与各份合同都可能不同。用别人的费率算自己的账，结论一定跑偏。

## 业内常见的错误做法

- 把堂食定价直接搬到外卖，忘了佣金与包装是随单新增成本。
- 用标价计算收入，忽略商家承担的满减与红包。
- 把佣金、包装、配送全部塞进「其他费用」，永远看不出单笔贡献利润。
- 为冲单量参加高强度活动，没有单笔贡献利润下限。
- 把「外卖营业额占比提升」当成增长成绩，不显示渠道贡献利润。

## 推荐的解决方案：一单一表

对每一笔典型订单，写清这些字段：**标价、商家承担的补贴、实收、食材、包装、佣金、配送相关费用、商家承担的营销费用**。

- 单笔实收 = 标价 − 商家承担补贴
- 单笔总变动成本 = 食材 + 佣金 + 包装 + 配送 + 随单营销
- **单笔贡献利润 = 单笔实收 − 单笔总变动成本**
- 佣金盈亏上限 = (实收 − 食材 − 包装 − 配送 − 随单营销) ÷ 标价

最后一项特别有用：它告诉你这个价格结构最多能承受多少佣金率，超过就是白干。注意贡献利润**未扣人工、房租、水电**，不是净利润；它只回答「这一单有没有往固定成本的坑里填土」。

## 直接照着做：7 步渠道体检

1. 从商家后台导出近 4 周账单，确认佣金计费基数与各项补贴承担方。
2. 选 3 个销量最高的外卖单品，逐项填写一单一表。
3. 按加权平均算出外卖渠道的单笔贡献利润与贡献利润率。
4. 与堂食同口径对比：堂食没有佣金与包装，但占用桌位与服务时间。
5. 找出贡献利润为负的单品：先调规格 / 组合 / 起送价，再决定是否下架。
6. 给活动设「单笔贡献利润下限」与「商家补贴月度上限」，到线即停。
7. 每周按渠道输出营业额与贡献利润两张图，别只看第一张。

## 一个模拟案例（演示数据，非真实门店）

> 以下为**模拟订单的演示数据**，不对应任何真实平台费率或真实门店账单，请以自己的后台账单为准。

一份标价 38 元的套餐：食材 13 元、佣金率 20%（按标价简化计算 = 7.6 元）、包装 2.5 元、配送相关费用 3 元、商家承担补贴 5 元、随单营销 2 元。

| 项目 | 金额 |
| --- | --- |
| 标价 | 38.00 元 |
| 商家承担补贴 | −5.00 元 |
| 单笔实收 | 33.00 元 |
| 食材 + 包装 + 佣金 + 配送 + 营销 | 13 + 2.5 + 7.6 + 3 + 2 = 28.10 元 |
| **单笔贡献利润** | **4.90 元** |
| 贡献利润率 | 4.90 ÷ 38 ≈ 12.9% |
| 佣金盈亏上限 | (33 − 13 − 2.5 − 3 − 2) ÷ 38 ≈ 32.9% |
| 不亏钱的最低标价 | (13 + 2.5 + 3 + 5 + 2) ÷ (1 − 20%) = 31.88 元 |

一单只填 4.9 元进固定成本的坑。若月固定成本 49000 元，光靠这类订单需要约 10000 单/月（333 单/天）才保本——这就是为什么「80 单/天看起来很忙，月底却还是紧」。

改善方向不是喊「少做外卖」，而是逐项看：能不能用组合提高实收、降低包装规格、把补贴换成低成本加购、把不适合运输的菜只留给堂食。

## 相关公式与口径

- 单笔贡献利润 = 实收 − 食材 − 包装 − 佣金 − 配送 − 随单营销
- 贡献利润率 = 单笔贡献利润 ÷ 标价
- 佣金盈亏上限 = (实收 − 食材 − 包装 − 配送 − 随单营销) ÷ 标价
- 不亏钱的最低标价 = (食材 + 包装 + 配送 + 补贴 + 随单营销) ÷ (1 − 佣金率)

各平台佣金计费基数、配送费承担与结算周期不同，本文为简化演示口径；正式结论请以商家后台账单与合同为准。税务、发票与平台合规事项请以所在地现行法规为准。

## 老板避坑提醒

- 「满减由平台补」和「满减由商家补」差的是利润，签约前看清楚。
- 冲单量前先算单笔贡献利润下限，负贡献的规模增长没有意义。
- 别把不适合运输的菜放上外卖，差评成本也算在渠道账里。
- 渠道对比要同口径：堂食占用桌位，外卖占用打包区与平台费用，两边都别只算自己方便的那部分。
