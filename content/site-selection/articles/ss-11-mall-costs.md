商场的优势很真实：客流基数、环境、统一物业、不用自己修厕所。但商场的报价单也很容易让人只看见「月租」那一行。

> 先给结论：比较商场铺与街铺，不能比月租，要比「每月全部占位成本 ÷ 该铺位门前有效客流」以及整段租期现金支出来看。把报价单逐行抄进一张表，再开始算账。

## 一、逐行拆开报价单

| 费用项 | 常见计法 | 容易忽略的点 | 要问的书面问题 |
|---|---|---|---|
| 固定租金 | 元/㎡/月 或 元/月 | 是否含税、含物业 | 发票与税点怎么开 |
| 保底抽成 | 取「固定租金」与「营业额 × 扣点」较高者 | 营业额基数含不含外卖、团购、退款 | 扣点基数定义写进合同 |
| 物业费 | 元/㎡/月 | 是否随年递增 | 递增规则 |
| 推广费 / 营销基金 | 固定额或按营业额比例 | 活动是否真的带来你那个楼层的客流 | 费用对应什么服务 |
| 空调加时 | 按小时计费 | 晚餐与夜宵时段是否超出统一供冷时间 | 加时单价与申请流程 |
| 垃圾清运 / 隔油池清掏 | 固定或按量 | 餐饮专项收费常单独列 | 收费标准与频次 |
| 水电能耗 | 分表计量 + 公摊 | 公摊口径与损耗系数 | 计量方式与历史账单 |
| 装修期费用 | 管理费、押金、垃圾清运 | 装修期是否免租、是否照收物业 | 免租期起止与重叠 |
| 招牌 / 外摆 / 排烟管道 | 审批费或使用费 | 位置与尺寸受限 | 书面许可条件 |
| 押金 / 履约保证金 | 押几付几 | 退还条件与扣款条款 | 退还时限与情形 |

## 二、把抽成换算成「实际月租金」

**公式一 · 商场实际月租赁成本**

`实际月成本 = max(固定租金, 月营业额 × 扣点) + 物业费 + 推广费 + 空调加时 + 清运费 + 其他固定费用`

**公式二 · 临界营业额**

`临界营业额 = 固定租金 ÷ 扣点`

超过这个营业额，抽成开始高于固定租金，商场与你一起分享增长；没超过，你付的实际是固定租金。看清临界点在哪，才知道自己预测的三情景里哪个会触发抽成。

演示计算：固定租金 18,000 元、扣点 12%、物业等固定附加费 6,000 元，则临界营业额 = 18,000 ÷ 0.12 = 150,000 元/月。若基准情景月营业额 113,400 元，抽成项未触发，实际月成本 = 18,000 + 6,000 = 24,000 元；若乐观情景达 180,000 元，抽成 = 21,600 元，实际月成本升到 27,600 元。**营业额变好，成本也跟着涨**，这一点在做敏感性分析时必须写进去。

## 三、楼层与动线：商场客流不是你的客流

| 位置 | 常见客流特征 | 调查动作 |
|---|---|---|
| 地铁 / 主入口连通层 | 经过量大、赶路比例高 | 分方向计数，看停留率 |
| 餐饮层 | 目的性消费、午晚集中 | 同层同业态逐家数进店 |
| 高楼层死角 | 依赖导流与品牌 | 看扶梯 / 直梯到达路径与导视 |
| 中庭 / 主动线拐角 | 可视性差异极大 | 30m / 10m / 门前各拍一张 |

调查时把「商场大门客流」「该楼层客流」「铺位门前客流」「铺位门前目标客群」四层分开记。用第一层去算营业额，是商场选址最典型的高估来源。

### 经营自主权也要折成成本

- 营业时间是否必须跟随商场，能否做早餐或夜宵；
- 菜单与价格调整、外卖自取、外摆是否被限制；
- 排烟条件由商场统一提供还是自建，容量是否够；
- 装修审批周期、施工时段、围挡要求对开业倒排的影响；
- 商场整体调铺、业态调整、活动期封路是否写进合同。

这些限制不会出现在报价单里，但会直接改变你的营业时段与峰值产能。

## 四、常见错误与通过标准

| 常见错误 | 为什么会出事 | 正确做法 |
|---|---|---|
| 只比固定租金 | 附加费可占相当比例 | 算实际月成本与整段租期成本 |
| 忽略抽成基数定义 | 外卖与团购是否被计入差异大 | 书面定义并写进合同 |
| 用商场总客流预测 | 楼层与动线衰减极大 | 在铺位门前分时段计数 |
| 忽略装修期收费 | 开业前现金已大量流出 | 列进现金流时间轴 |
| 没谈退出条款 | 商场调铺或客流下滑时难退出 | 明确解约与退还条件 |

**通过标准**：报价单每一行已列入成本表；临界营业额已算出；四层客流分别有记录；营业时间、排烟、装修审批与退出条款均有书面答案；整段租期现金流出图已按最紧月份检查。
