手里只有一个铺位时，人会自动替它辩护；有三个时，才会开始比较。但比较也很容易变成「给已经喜欢的那一个打高分」。

> 先给结论：**先否决，再算账，最后评分**。一票否决项独立判定，不参与平均；加权评分用于暴露短板，不用于输出「签约」结论。

## 一、三步顺序

### 第一步：一票否决（不加权、不平均）

| 否决项 | 判定方式 | 任一不成立 |
|---|---|---|
| 出租权与产权材料 | 书面材料齐备 | 淘汰 |
| 房屋用途可办餐饮 | 书面 / 监管口径 | 淘汰 |
| 排烟、排污、电力、消防条件 | 物业书面条件 | 淘汰 |
| 原租约转让权、欠费与储值债务 | 三方材料 | 淘汰 |
| 门前遮挡、围挡、长期施工 | 书面说明 | 标为待核实，不进入签约 |

### 第二步：算账（每个铺位单独算）

`月经营利润 = 月营业额 × 边际贡献率 − 月全部租赁成本 − 其他月固定成本`

`保本营业额 = (月全部租赁成本 + 其他月固定成本) ÷ 边际贡献率`

`回本周期(月) = 初始投入 ÷ 月经营利润`（月经营利润 ≤ 0 时不计算，直接标记不可行）

`租金承受上限 = 保守情景月营业额 × 边际贡献率 − 其他月固定成本 − 必要月利润`

### 第三步：加权评分（只用于比较长短板）

**公式 · 加权总分**

`加权总分 = Σ(单项得分 × 权重) ÷ Σ权重`，单项按 1–10 分打分，权重按品类重要性设定（1–5）。

评分维度建议十项：商圈潜力、目标客群匹配、客流质量、可见度与动线、竞争强度、铺位工程条件、租金与总成本、租期与条款、外卖与取餐条件、扩展与退出空间。

**权重设定规则**：按品类写理由，不按偏好。写字楼快餐把「午市峰值客流」和「出餐 / 取餐动线」权重调高；社区正餐把「晚市与周末客群」「停车」调高。权重写进记录，避免看完铺再改。

## 二、演示：三个候选铺位放在一张表里

以下为演示计算，用于说明比较方法，不是任何真实门店或行业数据。

| 指标 | A 街边铺 | B 商场铺 | C 社区铺 |
|---|---:|---:|---:|
| 面积 ㎡ | 80 | 65 | 95 |
| 月全部租赁成本 | 20,000 | 24,000 | 15,000 |
| 转让费 / 初始投入 | 0 / 260,000 | 0 / 320,000 | 80,000 / 300,000 |
| 基准月营业额 | 113,400 | 126,000 | 94,500 |
| 保守月营业额 | 75,600 | 69,300 | 69,300 |
| 边际贡献率 | 60% | 58% | 62% |
| 其他月固定成本 | 31,000 | 33,000 | 28,000 |
| 保本营业额 | 85,000 | 98,276 | 69,355 |
| 保守情景月利润 | −5,640 | −12,806 | −320 |
| 基准情景月利润 | 17,040 | 15,080 | 15,590 |
| 加权总分 | 7.6 | 7.1 | 7.4 |
| 一票否决 | 无 | 排烟待书面确认 | 无 |
| 待核实项 | 2 | 4 | 1 |

**读表结论**：A 的加权分最高，但 B 存在排烟未书面确认（一票否决未关闭，不能因分数参与比较）；A 与 C 的保守情景都不过保本线，说明**三个铺位都需要重谈租金或改模型**，而不是「选 A」。C 的租金最低、保本线最低，但转让费让它初始投入更高，回本周期未必最短。

## 三、三种结论，写法要具体

| 结论 | 触发条件 | 结论里必须写什么 |
|---|---|---|
| 继续调查 | 有待核实项、样本不足 | 谁去核、核什么、什么时候复核 |
| 进入谈判 | 否决项关闭，保守情景可接受或差距可通过条件弥补 | 报价 / 目标价 / 退出价 + 要交换的条件 |
| 放弃 | 否决项无法关闭，或谈判后仍过不了保守情景 | 明确写出止损理由与备选方案 |

**不要写**「综合来看 A 更优，建议签约」。这句话没有退出价、没有待核实项、没有假设，等于把决策权交给情绪。

## 四、常见错误与通过标准

| 常见错误 | 为什么会出事 | 正确做法 |
|---|---|---|
| 看完铺再定权重 | 评分变成给偏好找理由 | 权重先写并注明品类理由 |
| 否决项参与平均 | 硬障碍被高分掩盖 | 独立判定，先淘汰 |
| 只比月租与面积 | 保本线、回本期与条款差异被忽略 | 用完整对比表 |
| 用基准情景做决策 | 保守情景才是安全垫 | 两档都列 |
| 结论只有「建议签约」 | 没有条件与退出价 | 三要素齐全 |

**通过标准**：三个铺位均已完成一票否决判定；每个铺位单独算过保本线与月利润；权重与理由先于打分写定；保守情景过不了保本线的铺位已写明「需谈到多少租金」；结论含退出价、待核实项与责任人。

**下一步**：把评分、方案与合同核查结果保存进工具，生成《最终签约决策报告》，把待核实问题带去逐条关闭。

> 本文数字为演示计算，用于说明公式与读表方式；评分不是投资成功概率，估算不构成投资、法律或财税建议。
